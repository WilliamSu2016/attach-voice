## 1. 产品定位

**AI Voiceover for Existing Videos** —— 一款 Windows 桌面应用，让用户为**已有的本地视频**添加 AI 生成的旁白配音。

- **形态**：桌面应用（本地处理，视频不上传，保护隐私）
- **核心场景**：用户提供脚本文本 → AI 合成语音 → 混合进已有视频 → 导出新视频（script-to-voice）
- **目标用户**：需要给录屏、教程、宣传片、Vlog 快速加旁白，但不想自己录音的个人创作者

### 非目标（明确排除，二期考虑）
- 语音转录（ASR）+ 翻译 + 多语言配音（dubbing）
- 离线 TTS（Piper）
- 波形可视化时间轴编辑器
- 背景音乐轨
- 云端处理 / 视频上传
- 视频剪辑（裁剪、转场、字幕烧录）

## 2. 关键产品决策（不可在实现阶段推翻）

| # | 议题 | 决策 | 理由 |
|---|---|---|---|
| **D1** | 脚本模型 | **支持多段**：段列表（文本 + 起始时间），支持 `.srt` 与 `[mm:ss] 文本` 导入 | 真实配音场景旁白总是分段对应画面；事后改造需重构数据模型 |
| **D2** | 音视频时长不匹配 | **画面绝不改动**：配音短则尾部补静音；配音长则截断；导出前必须弹窗提醒 | 用户预期是原视频画面绝对不动 |
| **D3** | ffmpeg 分发 | 优先使用系统 ffmpeg；检测不到则引导**一键下载 LGPL 静态构建**到应用目录 | 规避 GPL 许可风险，同时保证开箱可用 |
| **D4** | 视频编解码 | `-c:v copy -c:a aac`，仅重编码音轨；容器不兼容时才回退重编码视频 | 秒级导出 vs 分钟级导出 |
| **D5** | TTS 架构 | 定义 `TTSProvider` 抽象基类，edge-tts 为第一个实现 | edge-tts 是非官方逆向接口，存在单点失败风险 |
| **D6** | SRT 时间语义 | SRT 的起始时间用于定位配音；结束时间仅用于保存和导出字幕，不限制 TTS 音频时长 | 保持现有旁白时间轴规则，避免自动变速或因字幕显示区间截断旁白 |
| **D7** | 视频内嵌字幕 | 默认关闭的可选字幕轨；MP4 使用 `mov_text`，标记默认显示，播放器可关闭；不烧录、不因添加字幕重编码视频 | 保留画面与现有导出行为，让字幕显示由播放器控制 |

## 3. 用户流程（MVP）

1. **选择视频**：拖拽或文件选择本地视频 → 显示时长、分辨率、是否含音轨
2. **编辑脚本**：可增删改行的段落表格（起始时间 + 文本）；或导入 `.srt` / `[00:15] 文本` 格式
3. **选择音色**：按语言过滤（edge-tts 400+ 音色，不过滤不可用）→ 选音色 → 调语速 / 音调
4. **生成配音**：逐段调用 TTS 合成，显示进度，**可取消**；生成后每段可单独试听
5. **时长校验**：UI 显示「视频 X 秒 / 配音占用至 Y 秒」；若超出则弹窗提示将被截断（D2）
6. **选择混音模式**：
   - `replace`：替换原音轨
   - `overlay`：叠加原音轨，原声音量可调（默认 20%，不得写死）
7. **导出**：按各段 `start_time` 铺到时间轴上混音，`-c:v copy` 输出新视频
8. **附加**：「仅导出音频」，输出合成后的完整配音轨 mp3
9. **可选内嵌字幕（F15）**：视频导出时可启用「内嵌字幕」（默认关闭），使用当前分段表格的字幕。
   支持「字幕与配音一起导出」和「仅添加字幕、保留原声」两种场景；后者不要求生成配音。

## 4. 功能需求清单

### 必须（MVP）
- R1 本地视频导入（拖拽 + 文件对话框），并探测元信息（时长/分辨率/音轨存在性）
- R2 多段脚本编辑：增行、删行、改文本、改起始时间；时间格式与重叠校验
- R3 脚本导入/导出：`.srt` 与 `[mm:ss] 文本`
- R4 音色列表按语言过滤；语速、音调可调
- R5 逐段 TTS 合成，进度可见，任务可取消
- R6 每段独立试听
- R7 时长对比提示 + 超长截断确认弹窗
- R8 两种混音模式，overlay 原声音量可调
- R9 导出视频（`-c:v copy -c:a aac`）
- R10 仅导出音频（mp3）
- R11 配置持久化：音色、语速、输出目录、混音模式
- R12 错误处理与友好提示：ffmpeg 缺失、视频无音轨、格式不支持、TTS 网络失败/限流重试、段落时间越界
- R13 ffmpeg 缺失时一键下载并校验可用
- R14 SRT 文件导入、编辑与导出：支持将 `.srt` 导入分段表格并将编辑结果另存为 `.srt`；保留毫秒精度、多行文本及每条字幕的起止时间
- R15 视频内嵌字幕轨：将当前表格字幕封装为 MP4 中的一条 `mov_text` 字幕轨，支持与配音一起导出及仅添加字幕；详见下方范围约定

### 明确的行为约束
- 长文本必须按句子分块合成后拼接，避免单次请求超时/截断
- 触发视频重编码回退时，UI 必须明确提示「正在重新编码视频，耗时较长」，避免误认为卡死
- 默认输出容器为 `.mp4`，以降低重编码回退概率
- SRT 字幕的结束时间与 TTS 合成后的实际音频时长必须独立保存；重新生成配音不得覆盖字幕结束时间。
- 导入 SRT 后，配音从字幕起始时间开始，仍按下一段起始时间或视频结束时间截断；字幕结束时间不触发自动变速、截断或补静音。
- F14 的「导出 SRT」仍仅生成独立字幕文件；F15 是另行选择的视频内嵌字幕功能，二者互不替代，均不烧录字幕。
- 导入失败时必须指出条目或行号，且不得部分导入、静默跳过条目或替换用户当前表格内容。

### R15 范围约定（用户于 2026-09-06 确认；待实现）

| 项目 | 确定行为 |
|---|---|
| 入口与默认值 | 视频导出提供「内嵌字幕」选项，默认关闭；关闭时现有导出流程、前置条件和结果不变 |
| 字幕来源 | 使用当前表格的文本与时间，可来自 SRT 导入或手工编辑；不新增另一套字幕编辑器 |
| 字幕时间 | 使用编辑后的起止时间；缺少结束时间时沿用 F14 的 SRT 推导规则，不自动跟随 TTS 实际时长改写已有结束时间 |
| 配音与字幕 | 沿用现有 replace／overlay、原声音量、配音截断规则，只额外封装字幕轨 |
| 仅添加字幕 | 选择视频和字幕即可导出，不必生成配音；保留原音轨内容，无音轨视频不生成音轨；不应用配音混音参数 |
| 输出与视频 | 默认 MP4；字幕编码为 `mov_text`，不是直接把 SRT 当作 MP4 字幕编码；优先复制视频流，不因字幕重编码，不改变视频时长或剪辑画面；原有容器不兼容回退及提示规则不变 |
| 播放控制 | 新增字幕轨标记为默认显示；播放器可以忽略该标记，用户仍可关闭或切换字幕 |
| 范围限制 | 本次只新增一条字幕轨，不做字体、字号、位置编辑、多语言多字幕轨管理、自动翻译或字幕烧录 |
| 兼容性承诺 | 是否默认显示、换行和样式由播放器决定；不承诺所有播放器一致，也不因播放器不支持而回退为字幕烧录 |

视频内嵌字幕不改变 F14 独立 SRT 导出、逐段/整轨音频试听、仅导出音频和原有配音功能。
纯字幕导出不依赖 TTS 合成；需先加载视频，但不新增应用内视频字幕预览功能。

## 5. 验收标准（可度量，产品层）

| ID | 标准 | 度量方式 |
|---|---|---|
| **A1** | 输出视频画面时长与原视频完全一致 | `ffprobe` 读取时长，误差 < 0.05s |
| **A2** | 各段配音在输出中的实际起始时间与设定值一致 | 音频能量起点检测，偏差 < 0.2s |
| **A3** | 10 分钟 1080p 视频导出耗时 < 15s | 计时，且 `ffprobe` 确认视频流编码参数与源一致（证明未重编码） |
| **A4** | 输出文件可被主流播放器播放 | VLC / Windows Media Player / 浏览器实际打开 |
| **A5** | 配音总时长超出视频时，导出前出现明确提示，且实际行为为**截断**而非改动画面 | 手动/UI 测试 + A1 断言 |

## 6. 运行环境要求（产品承诺）

**对硬件要求极低，无需 GPU，普通办公电脑即可流畅运行。**
原因：TTS 在云端（本地零推理）+ 视频不重编码（仅磁盘 I/O）。

### 最低配置
| 项目 | 要求 |
|---|---|
| CPU | 任意双核 x64 |
| 内存 | 4 GB |
| 显卡 | **不需要**（集显即可） |
| 磁盘 | 500 MB 程序 + 约 2 倍源视频大小的临时/输出空间 |
| 网络 | **必需**，带宽要求低（1 分钟语音约 1 MB） |
| 系统 | Windows 10/11 x64（PyQt6 跨平台，macOS/Linux 亦可运行） |

### 推荐配置
四核 CPU + 8 GB 内存 + SSD。此配置下满足 A3（10 分钟 1080p < 15s）。

### 唯一的高 CPU 例外
`-c:v copy` 失败回退到视频重编码时，耗时从秒级升到分钟级。必须有 UI 提示。

## 7. 已知产品风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| edge-tts 是非官方逆向接口 | 接口变更 / IP 限流导致核心功能不可用 | D5 抽象隔离；失败重试 + 友好报错；二期接入 Piper |
| ffmpeg 许可 | 分发合规问题 | D3 不内嵌，运行时引导下载 LGPL 构建，README 注明许可归属 |
| QtMultimedia 打包遗漏 | 打包后试听功能失效 | 打包步骤单独验证试听 |
| 视频重编码回退 | 导出耗时暴涨，用户体验崩塌 | 默认 mp4 输出 + 明确 UI 提示 |
