# attach-voice

为已有本地视频添加 AI 旁白配音和可选内嵌字幕轨的 Windows 桌面应用。视频始终在本机处理，
不会上传到云端。

## 功能

- 导入本地视频并显示时长、分辨率和音轨信息。
- 编辑多段旁白脚本：起始时间、字幕结束时间和文本。
- 导入、编辑及导出 UTF-8 / UTF-8 BOM 编码的 `.srt` 字幕；保留毫秒级时间与多行文本。
- 按语言选择 edge-tts 音色，调整语速和音调，后台生成配音并支持取消。
- 单段试听，或按完整时间轴试听已生成配音。
- 导出完整旁白音轨为 MP3。
- 以替换原声或叠加原声的方式导出视频；叠加原声音量可调。
- 可选封装一条 MP4 `mov_text` 内嵌字幕轨。字幕由播放器显示或关闭，不烧录到画面。

## 运行环境

- Windows 10/11 x64
- Python 3.11 或更高版本
- 网络连接：edge-tts 合成语音时需要访问微软语音服务
- 4 GB 内存和任意双核 x64 CPU；推荐 8 GB 内存和 SSD

本应用不需要 GPU。正常导出会复制视频流，只处理音轨，因此速度主要受磁盘 I/O 影响。

## 安装

在 PowerShell 中进入项目目录：

```powershell
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

也可以通过项目提供的环境恢复脚本检查或安装依赖：

```powershell
bash init.sh
```

在 WSL 中执行 `init.sh` 时，脚本会优先使用 Windows 侧 Python。运行 GUI、测试和打包应使用
Windows PowerShell 与 `.venv\Scripts\python.exe`。

## 启动

```powershell
.\.venv\Scripts\python.exe -m src
```

查看版本：

```powershell
.\.venv\Scripts\python.exe -m src --version
```

## 使用

### 添加 AI 旁白

1. 点击 **选择视频**，或将视频拖入窗口。
2. 点击 **添加分段**，填写每段的起始时间和文本；也可以点击 **导入 SRT**。
3. 选择语言、音色、语速和音调，点击 **生成配音**。
4. 使用每行的 **试听** 按钮试听单段，或点击 **试听已生成配音** 按完整时间轴试听。
5. 选择混音模式：
   - **覆盖原声（replace）**：以 AI 旁白替换原视频音轨。
   - **与原声混音（overlay）**：保留原声并按滑块设置其音量。
6. 点击 **导出**，选择 MP4 输出位置。

视频画面时长不会因配音改变。配音超过视频末尾或与下一段重叠时会被截断，导出前会提示确认。

### 使用 SRT 字幕

点击 **导入 SRT** 载入字幕。每条字幕会成为可编辑分段，保留起始时间、结束时间及多行文本。
字幕结束时间只决定字幕显示区间，不限制 AI 配音时长。

点击 **导出 SRT** 可以保存当前编辑结果为独立字幕文件。支持的输入编码为 UTF-8 和 UTF-8 BOM。

### 内嵌字幕轨

勾选导出区域的 **内嵌字幕** 后，输出 MP4 会增加一条 `mov_text` 软字幕轨：

- 已生成配音时，导出的视频同时包含配音和字幕。
- 未生成配音时，可直接导出字幕视频；原音轨会被保留。
- 不勾选该项时，原有视频导出行为不变。

软字幕不烧录到画面。支持该格式的播放器可选择显示、关闭或切换字幕；默认显示、换行和样式由
播放器及其设置决定。

## ffmpeg

应用需要 `ffmpeg` 和 `ffprobe` 来探测和导出媒体。查找顺序为应用目录的 `bin/`、系统 `PATH`
以及用户配置路径。

如果未检测到 ffmpeg，应用会引导下载 LGPL 静态构建，并在下载后执行 `ffmpeg -version` 校验。
ffmpeg 不随本项目源码或当前应用包分发。请遵守所下载 ffmpeg 构建的许可证与使用条款。

默认 MP4 导出使用 `-c:v copy` 复制视频流，音频使用 AAC。只有容器或编码不兼容时才会回退到
视频重编码，并会向用户提示该操作耗时较长。
